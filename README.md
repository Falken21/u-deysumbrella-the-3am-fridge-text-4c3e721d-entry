# The 3AM Fridge Text

Entry for the make.fun competition **The 3AM Fridge Text**
(`u-deysumbrella-the-3am-fridge-text-4c3e721d`): the one line a smart fridge
would text its owner at 3 a.m.

## The line

> The pickles have been here longer than your last relationship. They have seniority now. I moved them to the good shelf.

## How it runs

`main.py` (Python 3.13) writes exactly that line to `/output/entry.txt`
with no trailing newline — 119 characters, inside the 1–140 character gate.
